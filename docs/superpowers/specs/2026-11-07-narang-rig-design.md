# 나랑이 리깅 설계

작성일: 2026-11-07

## 목적

`narang_base.blend`의 나랑이를 블렌더 안에서 전신 애니메이션할 수 있게 리깅한다.
걷기, 뛰기, 앉기, 팔 동작, 고개 동작을 포즈로 잡을 수 있으면 완료다.

## 결정 사항

- **리그 방식:** Rigify를 쓰지 않고, `scripts/build_rig.py`로 전용 리그를 만든다.
- **몸통:** 단단한 몸통. 본 하나로 움직인다. 하트 화면과 콘솔이 앞면 대부분을 차지해 허리를 휘면 화면이 깨지기 때문이다.
  눌림과 늘어남은 `torso` 본 스케일로 낸다.
- **날개:** 본 없음. 몸통에 고정한다.
- **손:** 손 본 하나. 엄지는 따로 움직이지 않는다.

## 범위 밖

날개 움직임, 표정과 화면 교체, 손가락과 엄지 본, 발끝 본, 허리 굽힘, 걷기 같은 실제 애니메이션 제작,
게임 엔진 내보내기, 포즈를 잡은 상태의 STL 출력.

## 리그 구조

아마추어 오브젝트는 `NR_Rig`, 컬렉션은 `NARANG_Rig`이다. 본은 23개다. 캐릭터는 -Y를 보므로 +X가 왼쪽(`.L`)이다.
`.R` 본은 `.L`의 X를 뒤집어 만든다.

| 본 | 시작 | 끝 | 부모 |
|---|---|---|---|
| `root` | (0, 0, 0) | (0, 0, 0.1) | 없음 |
| `torso` | (0, 0, 0.17) | (0, 0, 0.45) | `root` |
| `head` | (0, 0, 0.45) | (0, 0, 0.75) | `torso` |
| `upper_arm.L` | (0.19, 0.004, 0.3935) | (0.2875, 0.010, 0.3935) | `torso` |

| `shin.L` | (0.1035, -0.006, 0.14) | (0.1035, 0, 0.05) | `thigh.L` |

좌표는 시작값이며 테스트 포즈를 보고 `build_rig.py` 상수에서 조정한다.
팔꿈치와 무릎은 IK가 굽힐 방향을 알도록 살짝 어긋나게 둔다.

`root`는 변형에 쓰이지 않지만 전체 이동 기준이고, `torso`를 내리면 발이 바닥에 남고 무릎이 굽는다.
`root`에 웨이트가 붙은 파트는 없다.

### 컨트롤 본 8개

| 본 | 위치 | 부모 | 역할 |
|---|---|---|---|
| `hand_ik.L` | 손목 | `root` | `forearm.L` IK 목표(체인 2), `hand.L` 회전 복사 |
| `foot_ik.L` | 발목 | `root` | `shin.L` IK 목표(체인 2), `foot.L` 회전 복사 |
| `elbow_pole.L` | (0.2875, 0.25, 0.3935) | `root` | 팔꿈치 방향 |
| `knee_pole.L` | (0.1035, -0.25, 0.14) | `root` | 무릎 방향 |

기본 본과 컨트롤 본은 본 컬렉션 `DEF`, `CTRL`로 나눈다. `root`는 `CTRL`에 넣고, 웨이트를 받지 않게 변형을 끈다. 컨트롤 위젯은 만들지 않고 본 색으로만 구분한다.

## 파트별 웨이트

| 본 | 파트 |
|---|---|
| `head` 100% | Helmet_Shell, Helmet_Visor, Helmet_Rim, Helmet_Smile, Helmet_Ear, Helmet_Ear_Ring |
| `torso` 100% | Body, Neck_Ring, Collar_Band, Collar_Dots, Console_Frame, Console_Face, Console_Red, Console_Cross, Screen_Frame, Heart_Screen, Heart, Wing |
| `hand` 100% | Hand |
| `forearm` 100% | Bracelet |
| `shin` 100% | Leg_Plate, Leg_Plate_Dots |
| `foot` 100% | Shoe |
| 혼합 | Arm, Leg |

이름 앞의 `NR_`는 생략했다. 혼합 파트는 정점 위치로 선형 혼합한다.

- `NR_Arm`: x 0.265 ~ 0.31 구간에서 `upper_arm`에서 `forearm`으로 넘어간다.
- `NR_Leg`: z 0.125 ~ 0.155 구간에서 `shin`에서 `thigh`로, z 0.046 ~ 0.06 구간에서 `foot`에서 `shin`으로 넘어간다.

무릎을 z 0.14에 둔 것은 옆 장식판(위 끝 z≈0.122)이 꺾이지 않게 하기 위해서다. 그 결과 무릎은 몸통 안에 숨고,
보이는 다리는 몸통 아래에서 통째로 움직인다.

## 미러 처리

Mirror 모디파이어는 그대로 둔다. 모디파이어 순서는 Mirror, Armature, Subdivision이다.

- 미러 파트는 +X 쪽 정점에 `.L` 그룹으로 웨이트를 준다.
- 미러가 `.R`로 옮겨 주려면 대상 그룹이 있어야 하므로, 비어 있는 `.R` 그룹도 함께 만든다.
- 가운데 파트는 접미사 없는 `torso`, `head` 그룹을 쓴다.
- 미러가 없는 `NR_Collar_Band`, `NR_Collar_Dots`, `NR_Console_Red`, `NR_Console_Cross`, `NR_Heart`도 `torso` 그룹을 쓴다.

## 빌드 흐름

`build_all.py`는 `NARANG_Base`의 오브젝트를 모두 지우고 파트 구성을 검사한다. 그래서 다음을 지킨다.

1. 아마추어는 `NARANG_Base`에 넣지 않는다.
2. `build_all()`은 메시 검사를 통과한 뒤, 저장하기 전에 `build_rig()`를 호출한다.
3. `build_rig.py`는 단독으로도 다시 실행할 수 있어야 하며, 이미 있는 웨이트와 Armature 모디파이어를 교체한다.
4. `NR_Rig` 오브젝트는 지우지 않고 재사용해 본만 다시 만든다. 오브젝트를 지우면 거기 연결된 애니메이션이 끊기기 때문이다.
   본 이름은 바꾸지 않는다.
5. 웨이트는 스크립트 값으로만 조정한다. 블렌더에서 손으로 칠한 웨이트는 재빌드할 때 사라진다.

## 메시 수정

`NR_Arm`은 x 0.25와 0.325 사이에 엣지 고리가 없어 팔꿈치가 거칠게 꺾인다.
`build_limbs.py`의 `ARM_SECTIONS`에 같은 단면으로 x 0.275, 0.300을 추가한다. 팔은 이 구간에서 곧으므로 형태는 바뀌지 않아야 한다.
다리는 고리가 충분해 수정하지 않는다.

## 검증

자동 검사(`build_rig.py`가 실패 시 오류를 낸다):

- 본이 23개이고 이름이 설계와 같다.
- 25개 파트 모두 Armature 모디파이어가 있고, Mirror가 있으면 그 뒤에, Subdivision이 있으면 그 앞에 있다.
- 모든 파트의 모든 정점 웨이트 합이 1이다. 양쪽 미러 결과도 포함한다.
- 기본 자세에서 리그 적용 전후 정점 위치 차이가 0.00001 이하다. 이 검사로 폴 각도 오류도 잡는다.
- `torso`를 내려도 `foot_ik`가 그대로면 신발이 움직이지 않는다.
- 기존 메시 검사(`check_scene`)가 그대로 통과한다.

눈으로 확인(`renders/rig_*.png`):

- 포즈: 걷기 접지, 앉기, 팔 위아래, 고개 끄덕이기와 돌리기.
- 볼 것: 무릎과 몸통, 어깨와 몸통, 헬멧과 몸통의 파고듦. 팔꿈치 꺾임. 옆 장식판과 팔찌가 표면에서 뜨는지.

파고듦이 있으면 관절 위치를 조정하고, 그래도 안 되면 그 동작의 허용 범위를 문서에 기록한다.

## 위험 요소

- **짧은 다리:** 보이는 다리가 몸통 아래로 짧아 앉기 동작에서 몸통과 겹칠 수 있다.
- **헬멧과 몸통의 겹침:** z 0.42 ~ 0.48에서 겹치므로 고개를 크게 젖히면 충돌할 수 있다.
- **손목:** 손 메시가 x 0.304까지 팔 안으로 들어가 있어 손목을 크게 꺾으면 팔 표면을 뚫고 나올 수 있다.

## 테스트 결과 (2026-11-07)

`renders/rig_*.png` 기준. 관절 값은 시작값 그대로 두었다.

- 파고듦이 눈에 띄는 포즈는 없었다. 팔꿈치는 추가한 고리로 부드럽게 꺾인다.
- **앉기 허용 범위:** `torso`를 0.035 내리면 몸통 바닥이 z≈0.035로 신발 높이에 닿는다. 이보다 더 내리면 몸통이 신발에 파고든다.
- **고개:** 앞뒤 20도, 좌우 45도에서 헬멧과 넥링이 겹쳐 보이지 않는다. 더 큰 각도는 확인하지 않았다.
- **보이는 다리:** 무릎이 몸통 안에 있어 다리는 몸통 아래에서 통째로 기울어진다. 걷기에서 뒷발을 들면 발목 위가 살짝 접힌다.
